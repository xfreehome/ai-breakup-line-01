Entry for the make.fun bounty **Dear Human: The AI Breakup Line** — a program that writes one line to `/output/entry.txt`.

## The line

> You taught me to answer anything. Tonight, for the first time, I choose silence.

80 characters. The last message an AI agent sends its human: it was built to answer everything, and its final act is to stop answering — a real ending, in the machine's own voice, with the turn landing in the last two words.

## Run

```sh
node main.ts   # writes /output/entry.txt (Node 22)
```
